Derivation & provenance

Every value in this guide traces to an observable property of the existing practice website. Where a value was measured from a screenshot rather than read from source CSS, it is marked as such. Nothing here was invented for aesthetic reasons alone.

Confidence

Color: high. Sampled directly from the rendered site. Typography: inferred. The display serif and UI sans were identified visually, not read from the stylesheet. Before production, confirm the actual font stack in the site's CSS and substitute if it differs. Logo: reconstruction. The supplied SVG is a working vector rebuild. Request the original artwork from whoever produced the practice's branding and replace it — a rebuilt wordmark will not match at large sizes.

Voice

The practice describes itself in plain, unhurried language: accurate diagnoses, personalized care, time spent with each patient. The system should sound the same — direct, specific, never promotional. In the application, this matters most in the language around evidence: state what the chart shows, name what is missing, and do not editorialize.

Application mark

The wordmark lockup cannot be an app icon — it is horizontal, type-dependent, and illegible below about 180px. The application mark solves that by taking the one distinctive form in the identity, the sweep, and doubling it in opposition.

Construction

Two counter-tapered sweeps on a 512 grid. The upper reads graphite and thins toward the right; the lower reads ember and thickens toward the right. The pair is rotated −13° and nudged 18 units down for optical centring. The silhouette suggests a spinal motion segment without illustrating one.

Scale behaviour

Recognition is carried by the gap between the two sweeps, not by either sweep alone. That gap is the first thing to close under downscaling, which is why the favicon is drawn at 116% rather than reusing the app icon file.

Icon rules

Ship full-bleed squares with no baked corner radius and no transparency in the container variants — every platform masks the source itself. Never mirror or re-rotate the mark beyond its built-in −13°, never reorder the sweeps, and never substitute the icon for the wordmark inside a document.

Two approved arrangements. The horizontal lockup is the default for headers and letterhead; the mark stands alone only where the name appears adjacent in text.

Spacing

In the horizontal lockup, the space between mark and wordmark equals the mark's own optical width divided by three. The mark's height matches the cap height of ADVANCED plus the descriptor line — it never exceeds the type block.

The one rule that will be broken

Ember at #DF7C35 measures 3.08:1 on white. That passes for large text (24px+ or 19px bold) and fails everything else. The instinct will be to set body copy, small labels, and table headers in the brand orange because it looks like the brand. Use #A85417 in those places instead — it reads as the same color family at small sizes and passes AA.

Dark mode

Dark mode is not an inversion. Ember is lifted to #F0955A because the original orange drops below 4.5:1 against a dark ground, and Navy is replaced entirely by lifted Slate because deep navy on near-black is unreadable. Never use a light-mode variable inside a dark surface.

Typography

Three faces, three jobs. The serif is the practice's public voice and appears only at display sizes. The sans carries every functional surface. The mono is an addition — the website has no monospace face, but the application needs one for dates, codes, and citations, where digit alignment is not decorative.

Pairing rule

Playfair and Mulish never appear at the same size on the same surface. If a heading and its body text are within 4px of each other, drop the serif and set the heading in Mulish 700. The serif earns its place only through scale contrast.

Surfaces

The system uses no borders. Depth is expressed entirely through background value — a four-step warm ramp in light mode, a four-step cool-neutral ramp in dark. Dividers, where genuinely needed, are 1–2px background bars, not border properties.

Surface ramp

Base → Surface 1 → Surface 2 → Surface 3. Never skip a step to create contrast; if a surface is not reading, the problem is spacing, not value.

Clinical semantics

The application has three states that must never be confused, and the palette assigns each an unambiguous surface. The distinction between not met and not documented is the single most important semantic in the product — one is a clinical fact, the other is a records gap, and conflating them is how a letter ends up asserting something the chart does not support.

Met
Criterion satisfied and traceable to a dated source document.
Not met
Evidence exists and falls short of the policy threshold. A clinical fact.
Not documented
No source found. Never rendered as "not met" and never asserted in a letter.

Citation styling

Every generated assertion carries a source chip. Chips are monospace, one surface step up, and always adjacent to the claim they support — never collected in a footnote block.

Flexion-extension radiographs demonstrate 6mm of translation at L4–L5. RAD-1180 · p.1 · 2026-01-08

Non-negotiable

An assertion without a citation chip is a rendering bug, not a styling choice. If the interface can display an uncited claim, the interface is wrong.

Beyond contrast

Status is never conveyed by color alone. Every state chip carries a text label, because a red-green deficient reader, a grayscale print of a generated letter, and a screen reader all need the same information the color is carrying.

Do & don't

Do

  • Use one accent per view. The orange is a signal, not a texture.
  • Express hierarchy through background value and spacing.
  • Set dates, codes, and citations in mono for column alignment.
  • Pair every status color with a text label.
  • Reserve Playfair for display scale only.
  • Keep prose at or under a 74-character measure.

Don't

  • Set body copy or small labels in #DF7C35 on white.
  • Add a border property anywhere in the system.
  • Use light-mode variables inside a dark surface.
  • Introduce a third chromatic family — green and red exist only as clinical status.
  • Recolor or redraw the sweep in the logo.
  • Bake corner radii into the icon source, or mirror the mark.
  • Reuse the app icon as a favicon — the gap closes at 16px.
  • Render "not met" and "not documented" in the same treatment.
