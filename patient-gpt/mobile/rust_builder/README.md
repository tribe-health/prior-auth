# patient_gpt_ffi

Generated by `flutter_rust_bridge_codegen integrate` (2.12.0) and retargeted at
the shared workspace crate `crates/patient-gpt-ffi` (library `patient_gpt_ffi`).
cargokit compiles that crate during the iOS (CocoaPods script phase) and Android
(Gradle) builds. The `cargokit/` directory is vendored upstream code with one
local patch: `CrateInfo.libraryName` (`build_tool/lib/src/cargo.dart`) maps the
package name `patient-gpt-ffi` to Cargo's library name `patient_gpt_ffi`, which
upstream cargokit used verbatim and so failed to find the built artifacts.

The package name `patient_gpt_ffi` is load-bearing: on iOS the
flutter_rust_bridge loader opens `patient_gpt_ffi.framework/patient_gpt_ffi`,
the framework CocoaPods builds from this pod.
