# Spec Delta

## Purpose

Defines PatientGPT's Android on-device chat engine on devices and arm64
emulators, running on the CPU backend without UAR.

## ADDED Requirements

### Requirement: Android streams a local reply with UAR absent
On an Android device or emulator (arm64-v8a or x86_64) with a `ready` LiteRT-LM
chat model,
a `local` onboarding run SHALL stream a reply generated by that model as the
`local-chat` event sequence, using the CPU backend.

#### Scenario: Emulator reply
- **WHEN** a user sends an onboarding message on an API 34 or later emulator with at least 4 GiB of RAM
- **THEN** the reply appears incrementally and the run ends with `RUN_FINISHED`

### Requirement: Android has no UAR lane this phase
The Android build SHALL NOT link UAR. Its `uar` runs SHALL be refused with
`lane_unavailable`.

#### Scenario: UAR run on Android
- **WHEN** an Android build receives a `uar` run
- **THEN** it is refused with `lane_unavailable` and a following `local` onboarding run succeeds
