Spine in conversation

The PatientGPT mark is the practice’s spine inside a speech bubble: the surgeon’s case, spoken. It was chosen on 4 October 2026 from three concepts. This board shows the mark everywhere the application puts it, in both themes, and the rules that keep it the same across the web app, the desktop app and the phone.

The mark

Four forms, one drawing. The bubble changes colour with the surface; the spine inside it never changes. Below 24 px the favicon cut takes over, with the spine as a single bold stroke.

Colour

The application’s own tokens, nothing added. Three embers do three jobs: one lives only in the mark, one is text and buttons on white, one is text and buttons on dark. Grey is the upper sweep and takes the surface’s grey.

Wordmark and type

Mark at a quarter scale, then the name in Playfair Display 600, the display face the app already uses. The practice name is never part of the wordmark; it sits under it as a separate line where there is room. The text is live here and must be outlined for production.

Application icons

One master, four platforms. The tile is full-bleed navy; each platform applies its own corner. Android’s adaptive masks cut deepest, so the bubble stays inside the central 66 %.

In the application

The mark is PatientGPT’s voice. It appears once in the chrome, as the sidebar brand, and then only where PatientGPT speaks: beside assistant turns, in the thinking state, on the launch screen and in notifications. It is not a decoration for empty space.

Rules

Short, because the mark is simple. The practice’s spine stays the practice’s; PatientGPT is always the spine in the bubble.

Do

  • Use the navy bubble on white and light surfaces, the slate bubble on dark, the white bubble on navy.
  • Keep the spine exactly as drawn in the practice logo, at 60 % inside the bubble.
  • Use the favicon cut under 24 px: browser tab, window title bar, Windows taskbar.
  • Set the wordmark in Playfair Display 600, ink on white, paper on dark.
  • Put the mark beside assistant turns and in the thinking state, where PatientGPT is speaking.
  • Use the full tile for notifications and any place the icon represents the installed app.

Don’t

  • Don’t use the bare sweeps for PatientGPT; alone they are Advanced Spine & Orthopedics.
  • Don’t recolour the bubble ember, grey or any other colour, and don’t outline it.
  • Don’t set text in mark ember #DF7C35; text uses #A85417 on white and #F0955A on dark.
  • Don’t rotate the mark, add a shadow, or place it on an ember surface.
  • Don’t put the mark in empty states, cards or headings as decoration.
  • Don’t stretch the tail or move it; it always points to the lower left.
