## Gotchas

- `python3` on this machine is a shim that hangs; use `/usr/bin/python3`.
- `gh pr create` with body text inline can trip a hook; use `--body-file`.
- cargokit is vendored and patched (Gradle 9, compileSdk 36). Re-vendoring loses the patches.
- `surrealdb` sub-crates float unless `Cargo.lock` is kept; do not delete the lockfile.
- `flutter_launcher_icons` 0.14.4 rewrites `project.pbxproj` asset-catalog
  lines; `gen-app-icons.sh` snapshots and restores it. Run icons only through the script.
- The design-token generator renames Dart's reserved `void` to `voidState`.
- `genui` accepts A2UI version `v0.9` only, the web renderer `v0.9.1` only; the
  Flutter intake adapter maps exactly one to the other.
- Parent `scripts/audit.sh` check 2 calls the checker with `python3`; run it via `uv run` (pre-existing).
- Read `.prometheus/gotchas.md` before touching a subsystem.
