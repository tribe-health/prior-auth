## Why

The normative matrices and per-change inputs/outputs are recorded in [Web Case-to-Letter Workflow Contract](../../../docs/architecture/web-case-to-letter-contract.md).

## What Changes

- Freeze lifecycle, citation, criteria, privacy, command, fixture, and invalidation contracts before implementation.
- Preserve verified tenant scope, three evidence states, clinical authority, mandatory document/page/date provenance for every included generated assertion, no query cache, and shell-neutral application services.
- Use the browser as the behavioral acceptance surface while retaining typed HTTP/native command parity where commands are added.
