## Why

The parent RA06 final review must run once at the child phase-completion boundary, after every
implementation change is archived. Earlier Tier 2 runs and reviews belong to stale or premature
candidates and cannot close the child or parent.

## What Changes

Freeze the final candidate after implementation closes, run the 12-role campaign and parent Tier 2
as one deduplicated local integration matrix, assemble the complete packet, run deterministic and
isolated reviews, and close only the corrected RA06 task. Return explicit open RA11c and RA17
obligations to the parent.

## Capabilities

### New Capabilities

- `ra06d-03-parent-recertification`: Certify the corrected RA06 scope and return its immutable
  evidence to the parent KBD phase.

## Impact

Final candidate identity, 12 candidate-bound receipts, parent Tier 2 logs, review artifacts, RA06
task status and child handoff. RA11c and RA17 remain unchecked.
